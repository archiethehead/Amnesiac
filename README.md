# Amnesiac
The end is here, and along with it is a suspicious amount of rain, metallic humanoids closer to beast than man known as Empties, and Agents of a pre-apocalyptic elite known as the Karma Police who are, somehow, closer to beast than the Empties. Your goal? Make it to the next day. What is life but survival of the fittest.


## Installation
There isn't currently a build of the game available, debug or release, but the game can be ran and the source details interacted with through the Godot editor (.NET Godot, to be specific), which can be installed at the link below. Along with that, you'll also need either the latest .NET runtime (additionally linked below):

.NET -> https://dotnet.microsoft.com/en-us/download

Godot -> https://godotengine.org/download/windows

The repository itself, including both source code and assets, can either be downloaded as a Zip through GitHub, or cloned with standard Git commands:
> git clone https://github.com/archiethehead/Amnesiac


## Quick Start
The game is in a functional alpha state, and is able to be ran through the Godot editor. Additionally, the C# project for the game (available for Windows users with a copy of Visual Studio only) is set up to allow debugging through VS's JIT debugger, allowing for breakpointing and hot reloads. Functionally, the game currently allows you to move, interact with in-game objects, pick up and throw objects, evade a seeking AI, and smash a destructible, with a built in console that can be activated with `, and comes with a help command.
